ThreadSanitizer build (-fsanitize=thread -g -O1 -fno-omit-frame-pointer), WSL2 Ubuntu 22.04, g++ 11.4.0.
Built with: cmake -S . -B build_tsan -DCMAKE_BUILD_TYPE=Debug -DENABLE_TSAN=ON && cmake --build build_tsan -j6

Run with setarch -R (required under WSL2: TSan's shadow-memory layout
conflicts with WSL2's default ASLR and aborts on startup with "FATAL:
ThreadSanitizer: unexpected memory mapping" without it). All three
processes (commander, supervisor, actuator) were run through
setarch -R wrapper scripts so both the fault-monitor thread and the
message-handling thread inside the real supervisor process, the only
genuinely concurrent code in this repository, run under TSan, not just the
single-threaded unit test binary.
